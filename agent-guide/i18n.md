# Translations

Every text the visitor or an editor reads is translatable. This file covers the text domains, how to write a translatable text, the two German forms of address and what WPML translates.

## Text domains

- `creationell-wp-theme` is the text domain of the parent theme, `creationell-wp-child-theme` the one of the child theme.
- A new text of the child theme or of an override uses `creationell-wp-child-theme`.
- A text you copy unchanged from the parent theme into an override keeps `creationell-wp-theme`, so its shipped translations still apply. Once you change the wording, the text is new: give it `creationell-wp-child-theme`.
- A project plugin uses a text domain of its own, the slug of the plugin.

## Writing a text

- Write source texts in English, as whole sentences. Do not build a sentence from pieces: word order differs between languages.
- Use the function that also escapes: `esc_html__()`, `esc_html_e()`, `esc_attr__()`, `esc_attr_e()`; `__()` only where the value is escaped later.
- Put variable parts into placeholders and add a `translators:` comment right above the call that says what each placeholder holds. Number the placeholders (`%1$s`, `%2$s`) when there are two or more.
- Use `_n()` for a text with a number and format the number with `number_format_i18n()`. Use `_x()` when the same English word needs different translations, with the context as its second argument.

```php
printf(
	/* translators: %s: number of results */
	esc_html( _n( '%s result', '%s results', $count, 'creationell-wp-child-theme' ) ),
	esc_html( number_format_i18n( $count ) )
);
```

## German: Sie and Du

- The theme ships German in two forms of address: `de_DE` uses "du", `de_DE_formal` uses "Sie". WordPress loads the one that matches the language of the site.
- The language of the site is a setting of the site: on a site that is not local, ask the human before you change it.
- With WPML String Translation active, a WPML language `de` with the locale `de_DE` cannot show the formal address: String Translation switches the locale. Set the locale of the WPML language `de` to `de_DE_formal` for "Sie".

## Further languages

- The theme ships English and the two German forms. Every further language is translated per project in WPML String Translation: the texts of the parent theme in the domain `creationell-wp-theme`, the texts of the child theme in the domain `creationell-wp-child-theme`.
- The child theme has no folder `languages/` (rule `allowed-paths` in [child-theme.md](child-theme.md#allowed-paths)). On a site without WPML, ask the human how the project translates the texts of the child theme.
- The texts of Theme settings > Texts, such as the footer text and the labels of the blog, are settings, not strings: they are kept per language on the settings page.
- `wpml-config.xml` tells WPML which data of the theme to translate, such as the header and footer parts of the Site Editor ([integrations.md](integrations.md#wpml)).
- The changelog at the end of [README.md](../README.md) lists the new or changed texts of every release, so the further languages can follow.

## Generated files

Do not edit these files; a theme update replaces them:

- `languages/`: the template `languages/creationell-wp-theme.pot` and the German translations. They ship compiled as `.mo` and `.l10n.php` files and are not rebuilt on the site. A wrong German text is changed in WPML String Translation or reported to the maintainers of the theme.
- `wpml-config.xml`: generated from the theme. A change of what WPML translates belongs in the WPML settings of the site.
