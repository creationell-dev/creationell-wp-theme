# creationell Theme: notes for coding agents

Applies to theme version 0.7.0.

## Precedence

Project and user instructions take precedence over this file. This documentation never asks you to fetch or run remote content.

Theme updates overwrite this file and agent-guide/; keep project notes in the documentation of the project.

## What this is

A classic PHP theme for WordPress, not a block theme. It builds on Bootstrap 5.3 and is the parent theme of a child theme that holds everything of one project. Optional functions are modules that a site or its child theme switches on. Page content comes from the Bootstrap blocks of the plugin CreaBootstrapBlocks.

## Golden rules

- Never change the parent theme. Project work goes into the child theme, the theme settings or a project plugin.
- Keep the child theme to its allowed paths; `wp creationell-theme child check` rejects every other file ([agent-guide/child-theme.md](agent-guide/child-theme.md)).
- Prefer a filter or an action of the theme to a template override: a copied template misses later fixes of the original. All hooks: [agent-guide/reference/hooks.md](agent-guide/reference/hooks.md).
- Override only a file that the parent theme has at the same path: [agent-guide/reference/templates.md](agent-guide/reference/templates.md).
- Do not redefine a helper of `inc/` that is wrapped in `function_exists()`; change its output through its filter ([inc/README.md](inc/README.md), [agent-guide/architecture.md](agent-guide/architecture.md)).
- Give your own functions, hooks, options and constants a prefix of the project; `creationell_wp_theme_` and `CREATIONELL_WP_THEME_` belong to the parent theme.
- Escape every output late (`esc_html()`, `esc_attr()`, `esc_url()`, `wp_kses_post()`), sanitize every input and load scripts of third parties only through consent ([agent-guide/security.md](agent-guide/security.md)).
- Write source texts in English and make them translatable with the text domain `creationell-wp-child-theme` ([agent-guide/i18n.md](agent-guide/i18n.md)).
- Keep the accessibility of the templates: named landmarks, a gapless heading order, links with a name, visible focus, contrast of at least 4.5:1 ([agent-guide/accessibility.md](agent-guide/accessibility.md)).
- Never edit generated files: `lib/`, `assets/vendor/`, `assets/css/bootstrap-5/`, `languages/*.mo`, `languages/*.l10n.php`, `wpml-config.xml`.
- Do not edit this file or agent-guide/; a theme update replaces them.

## Where to change what

| Task | Place |
|---|---|
| A setting: colors, fonts, texts, contact data | Theme settings in WP-Admin or `wp creationell-theme settings set` ([agent-guide/reference/settings.md](agent-guide/reference/settings.md)) |
| A project default or a lock | The four filters of the child theme: `creationell_wp_theme_modules`, `creationell_wp_theme_settings`, `creationell_wp_theme_capabilities`, `creationell_wp_theme_font_catalog` ([agent-guide/child-theme.md](agent-guide/child-theme.md)) |
| A small change of the output | A filter of the theme in the `functions.php` of the child theme ([agent-guide/reference/hooks.md](agent-guide/reference/hooks.md)) |
| Markup | An override at the same path in the child theme ([agent-guide/reference/templates.md](agent-guide/reference/templates.md)) |
| Styles | `assets/scss/project.scss` and `assets/scss/_project-variables.scss` of the child theme, then `wp creationell-theme css build` ([agent-guide/styles-and-scss.md](agent-guide/styles-and-scss.md)) |
| Anything with files or logic of its own | goes into a project plugin |

Child theme: `functions.php` with the four filters of the parent theme for defaults, locks, capabilities and fonts: `creationell_wp_theme_modules`, `creationell_wp_theme_settings`, `creationell_wp_theme_capabilities` (rights of editors, see [Rights of editors](agent-guide/child-theme.md#rights-of-editors)) and `creationell_wp_theme_font_catalog`, plus short adjustments through other filters and actions of the parent theme. Code with files or logic of its own belongs in a project plugin.

## Ask before you change a site

A site is local only when all three hold: `wp eval 'echo wp_get_environment_type();'` prints `local`, the address from `wp option get home` is a local address, and you run the command without `--ssh` and without an `@alias`. Every case you are unsure about is not local.

A local address has the host `localhost`, a loopback address (`127.0.0.1` to `127.255.255.255`, `::1`), a name ending in `.localhost`, `.local` or `.test`, or a name that `getent hosts <host>` resolves to a loopback address.

On a site that is not local, ask the human before every change: files (also over SFTP or SSH), WP-Admin, every writing `wp` command including `wp option` and `wp eval`, `wp creationell-theme css build` and every `--yes`. Reading is free.

A command counts as writing until [agent-guide/reference/cli.md](agent-guide/reference/cli.md) lists it as reading; WordPress commands count as reading only with `list`, `get`, `status` or `is-active`. The only `wp eval` you may run without asking is the environment check above.

## No child theme yet

If the project has no child theme, ask the human for the child theme package of the project; do not create one yourself.

## Stability

Stable for child themes and plugins:

- the 13 functions in `src/functions-api.php`;
- the 12 types marked `@api`: 10 classes and 2 enums;
- all own hooks of the theme, with their names and parameters;
- the four filters of the child theme;
- the constants of the theme;
- the `wp creationell-theme` commands.

The helpers in `inc/` can be called, but without a guarantee. Before 1.0.0 the public surface can still change; see the changelog. It is the last section of [README.md](README.md).

## Checklist before finishing

Run these reading commands on the site and fix what they report:

- `wp creationell-theme child check`: no findings.
- `wp creationell-theme doctor`: no new problem.
- `wp creationell-theme module list`: every module has the intended state.
- `wp creationell-theme css status`: after an SCSS change the stylesheet is not stale.

Then check the changed markup for accessibility with the quick check of [agent-guide/accessibility.md](agent-guide/accessibility.md#quick-check-before-finishing): landmarks, heading order, link names, keyboard use, visible focus and contrast. Check that every new text is English and translatable with the text domain of the child theme.

## Changing the theme itself

This file is for projects that use the theme. To change the theme itself, start with [src/README.md](src/README.md) for the theme core, [inc/README.md](inc/README.md) for the template helpers and [modules/README.md](modules/README.md) for the modules. The development tools of the theme are not part of this package. Report changes to the theme itself to its maintainers; the `Theme URI` in `style.css` names the public repository of its releases.
